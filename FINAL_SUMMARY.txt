## 💡 HOW TO EXTEND

### Add a New Feature: Step-by-Step

**Example: Add Loyalty Points System**

1. **Database**: Add column to customers table
   ```sql
   ALTER TABLE customers ADD COLUMN loyalty_points INT DEFAULT 0;
   ```

2. **Backend**: Add method to Customer class
   ```php
   public function addPoints($customer_id, $points) {
       // Update database
   }
   ```

3. **Frontend**: Create my-points.php
   ```php
   $customer = new Customer($conn);
   $points = $customer->getPoints($customer_id);
   ?>
   <h1>Your Points: <?php echo $points; ?></h1>
   ```

4. **Done!** New feature is live

### Create manage-orders.php (Template Ready)

```php
<?php
require_once '../backend/includes/init.php';
require_login('admin');

$order_obj = new Order($conn);

// Get orders
$orders = $order_obj->getAll(50, 0);

// Update status
if ($_POST['update_status']) {
    $order_obj->updateStatus($_POST['order_id'], $_POST['status']);
}

// Assign delivery
if ($_POST['assign_delivery']) {
    $order_obj->assignDeliveryPerson(
        $_POST['order_id'], 
        $_POST['delivery_person_id']
    );
}
?>
```

## 🔧 Common Customizations

### Change Restaurant Name
- **File**: backend/includes/config.php
- **Find**: `define('SITE_NAME', 'Pizza & Burger Hub');`
- **Update**: Change to your restaurant name

### Change Delivery Charge
- **File**: backend/includes/config.php
- **Find**: `define('DELIVERY_CHARGE', 150);`
- **Update**: Change to your charge amount

### Change Tax Rate
- **File**: backend/includes/config.php
- **Find**: `define('TAX_RATE', 0.05);`
- **Update**: Change to 0.10 for 10% tax

### Add Payment Gateway
1. Create `backend/classes/Payment.php` methods
2. Add payment provider integration
3. Update checkout.php form
4. Test with test credentials

### Setup Email Notifications
```php
// Install PHPMailer
composer require phpmailer/phpmailer

// Use in Order class
require 'vendor/autoload.php';
$mail = new PHPMailer();
$mail->send();
```
